# KT AI Coding

Skills, MCP servers, CLI tools, and agent workflows for AI-assisted software engineering.

KT AI Coding collects practical tooling for Codex, Claude Code, Cursor, Windsurf, and other agentic coding environments. The focus is reusable infrastructure: skills, Model Context Protocol servers, command-line utilities, coding-agent workflows, and configuration templates.

中文说明见 [README.zh-CN.md](README.zh-CN.md)。
