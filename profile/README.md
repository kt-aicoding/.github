# KT AI Coding

Skills, MCP servers, CLI tools, and agent workflows for AI-assisted software engineering.

KT AI Coding collects practical tooling for Codex, Claude Code, Cursor, Windsurf, and other agentic coding environments. The focus is reusable infrastructure: skills, Model Context Protocol servers, command-line utilities, coding-agent workflows, and configuration templates.

中文说明见 [README.zh-CN.md](README.zh-CN.md)。

## Projects

### Skills

Reusable skills and instructions for AI coding agents.

### MCP Servers

Model Context Protocol servers for code context, review, search, browser automation, and developer workflows.

### CLI Tools

Small command-line tools for configuring and operating AI coding environments.

- [statusline-kit](https://github.com/kt-aicoding/statusline-kit): status line kit for Claude Code and Codex CLI.

### Agent Workflows

Templates and examples for multi-agent coding, review, research, debugging, and automation.

## Scope

This organization is for AI coding infrastructure. Broader AI engineering experiments and apps live at [kevinten-ai](https://github.com/kevinten-ai).
