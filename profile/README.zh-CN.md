# KT AI Coding

面向 AI 编程的 Skills、MCP Servers、CLI 工具和 Agent 工作流集合。

KT AI Coding 专注于 Codex、Claude Code、Cursor、Windsurf 等 AI 编程环境中的可复用基础设施：技能、Model Context Protocol 服务、命令行工具、编码 Agent 工作流与配置模板。

## 项目方向

### Skills

沉淀可复用的 AI 编程技能、指令和工作流。

### MCP Servers

为代码上下文、代码审查、搜索、浏览器自动化和开发者工作流提供 Model Context Protocol 服务。

### CLI Tools

用于配置和操作 AI 编程环境的小型命令行工具。

### Agent Workflows

用于多 Agent 编程、审查、调研、调试和自动化的模板与示例。

## 边界

这个组织只收纳 AI 编程基础设施。更广泛的 AI 工程实验和应用保留在 [kevinten-ai](https://github.com/kevinten-ai)。
